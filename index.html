Offline Bitcoin wallet

Generates a recovery phrase (BIP39) and native-segwit addresses (BIP84, m/84'/0'/0'/0/i) locally. Nothing is stored or transmitted.

    Read before using real money
    • Anyone who sees the phrase controls the funds. Write it on paper, never photograph it or store it in cloud notes.
    • This page uses your browser's secure random generator and audited open-source libraries (@scure/bip39, @scure/bip32), but a browser tab is not a hardware wallet. Your device may have malware or extensions that can read the screen.
    • For serious amounts, generate on a clean offline device (the page works with the network off), and send a small test amount first.
    • Run the self-test. It checks the code against the official BIP84 test vector.

    Split a secret (Shamir)

    Cut a secret into N shares so that any K of them rebuild it, while fewer than K reveal nothing at all. Good for seed phrases and inheritance plans.

      Recover

      Each share carries a built-in check, so mixed-up or missing shares give an error instead of a wrong answer. Store shares in different places and with different people.

      Hide a message in a picture

      Encrypts your message (AES-256-GCM, key from your passphrase), then hides the result in the lowest bits of an ordinary image. To everyone else it is just a picture.

      Reveal

      Limits you should know about
      • Send the PNG as a file. Messengers and social sites that recompress images (JPEG) destroy the hidden data.
      • The message is strongly encrypted, so nobody can read it without the passphrase. But specialist analysis can sometimes detect that something is hidden. Hiding is not the same as being undetectable.
      • Wrong passphrase and "no message here" look identical on purpose.

      Mirror this toolkit

      Takedowns only work on a single copy. This page packages itself so anyone can re-host it in under a minute.

      Host it somewhere (60 seconds each)

      Any Linux box or VPS (fastest, paste one thing)
      1. Click Copy shell installer above.
      2. Paste it into your terminal and press Enter. It creates a folder cypherpunk-toolkit with every file and checks them.
      3. Serve it: cd cypherpunk-toolkit && python3 -m http.server 8080
      4. Open http://your-server-ip:8080/. For HTTPS use Caddy: caddy file-server --domain example.com --root .
      GitHub Pages
      1. Create a new repository and upload the unzipped files (drag and drop works on the GitHub web UI).
      2. Settings, then Pages, choose Deploy from a branch, pick main and / (root).
      3. Your copy appears at https://USER.github.io/REPO/.
      Netlify Drop
      1. Unzip the download.
      2. Drag the folder onto app.netlify.com/drop.
      3. You get a live URL straight away.
      Cloudflare Pages
      1. Workers & Pages, then Create, then Pages, then Upload assets.
      2. Upload the unzipped folder and deploy.
      IPFS (no single host to take down)
      1. Install IPFS, then run ipfs add -r cypherpunk-toolkit.
      2. The last hash printed is the folder. Open it via any gateway as /ipfs/HASH/, or pin it with a pinning service.
      No host at all
      1. Download the single file version.
      2. Double-click it. It runs from disk and can still make more copies of itself.
      3. Pass it on by email, chat, or USB stick.
