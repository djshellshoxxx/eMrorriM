# Cypherpunk Toolkit Wiki

A single static page that runs in the browser: wallet recovery phrases, secret sharing, PNG steganography, OpenPGP, a
serverless WebRTC chat and a mirror/installer tab. No server, no accounts, no third-party requests (README).

- [Architecture Summary](Architecture-Summary)
- [Codebase Map](Codebase-Map)

This wiki does not assess the cryptography. The README names the third-party libraries bundled in `vendor.js`. Any
security review is separate work and has not been done here. Read the README "Honest limits" section before relying on the tool.
